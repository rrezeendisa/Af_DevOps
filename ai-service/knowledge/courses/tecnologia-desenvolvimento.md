# Fundamentos de desenvolvimento de software

- ID: CURSO-009
- Competência: tecnologia
- Nível recomendado: AVANCADO
- Pré-requisitos: lógica de programação e familiaridade com linha de comando

## Descrição
Introdução ao ciclo de desenvolvimento, controle de versão, testes e integração de componentes de software.

## Objetivos de aprendizagem
- Descrever etapas do ciclo de desenvolvimento.
- Compreender o papel do controle de versão e dos testes.
- Identificar práticas básicas de integração de software.
