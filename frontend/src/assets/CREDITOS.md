# Créditos e origem dos recursos visuais

Todos os recursos são locais; a aplicação não carrega imagens de URLs externas.

## Fotografias (`src/assets/fotos/`)

Formatos aceitos: `.avif` ou `.webp`. Basta colocar o arquivo com o nome abaixo: ele substitui o
*fallback* em SVG automaticamente. **Registre a linha correspondente ao incorporar cada imagem.**

| Arquivo (sem extensão) | Proporção | Tamanho sugerido |
| --- | --- | --- |
| `hero-aprendizado` | 4:5 | 1200×1500 |
| `hero-colaboracao` | 1:1 | 900×900 |
| `area-tecnologia` | 3:2 | 1200×800 |
| `area-comunicacao` | 4:5 | 800×1000 |
| `area-logica` | 1:1 | 800×800 |
| `experiencia-estudo` | 16:9 | 1600×900 |
| `login-acolhimento` | 4:5 | 1000×1250 |
| `capa-tecnologia` | 16:9 | 960×540 |
| `capa-seguranca` | 16:9 | 960×540 |
| `capa-comunicacao` | 16:9 | 960×540 |
| `capa-logica` | 16:9 | 960×540 |

Meta de peso: até 150 kB por foto (200 kB na maior); capas até 80 kB.

### Registro de origem

Para imagem gerada por IA, informe ferramenta, data, quem gerou, o *prompt* resumido e os termos de
uso. Para banco de imagens, informe autor, endereço de origem e licença.
